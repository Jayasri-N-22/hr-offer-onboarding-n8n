
# HR Offer & Onboarding Automation using n8n

## Project Overview
This project automates the HR offer and onboarding process using n8n.

## Features
- Candidate information collection
- Offer letter generation
- Email automation
- Onboarding workflow
- AI-assisted workflow

## Technologies Used
- n8n
- AI Agent
- JSON
- Email Automation

## How to Use
1. Download the workflow JSON file.
2. Import it into n8n.
3. Configure your credentials.
4. Execute the workflow.
